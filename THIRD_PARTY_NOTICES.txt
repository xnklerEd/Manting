Manting online speech protocol reference

The Microsoft Edge Read Aloud wire protocol was researched using rany2/edge-tts:
https://github.com/rany2/edge-tts
https://github.com/rany2/edge-tts/blob/master/src/edge_tts/communicate.py
https://github.com/rany2/edge-tts/blob/master/src/edge_tts/constants.py
https://github.com/rany2/edge-tts/blob/master/src/edge_tts/drm.py

SpeechService.swift is an independently written Swift implementation using macOS
system frameworks. No Python package, executable, or source from edge-tts is
included in this app. Protocol field names, format identifiers, endpoint details
and public client constants are used for interoperability.

This app is not affiliated with, sponsored by, or endorsed by Microsoft. Online
voices require network access and send the selected text to Microsoft's speech
service. Service availability and interface compatibility can change. The app
does not charge for speech and does not ask for an API key. The optional Tingting
voice is generated locally by macOS and does not send text to a speech service.
